# You Shine by Tasnia Rimy (Gulshan) — Website Preview

Single-page, mobile-first website preview for You Shine by Tasnia Rimy, Gulshan branch (House 29, Road 19, Gulshan, Dhaka).

- English / Bangla toggle (add `?lang=bn` to the URL to open in Bangla)
- "How do you want to feel today?" treatment finder that pre-fills booking
- Appointment booking (services, date, time) that sends to WhatsApp
- Vanity-mirror hero, services, visit steps, reviews, live "Open now" badge, map

Built by FutureStack Solutions. Photos are demo placeholders, to be replaced with the salon's own photos.
